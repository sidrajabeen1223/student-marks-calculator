# Student Marks Calculator

A beginner-friendly student project built with HTML, CSS, and JavaScript.

## Features
- Enter a student's name and marks in five subjects.
- Calculate total marks out of 500.
- Calculate percentage.
- Show a grade and pass/fail status.
- Validate marks between 0 and 100.
- Responsive layout for desktop and mobile.

## How to run
1. Extract the ZIP file.
2. Open `index.html` in any modern web browser.
3. Enter the student name and marks.
4. Click **Calculate Result**.

## Grade rules
- A+: 90% and above
- A: 80–89.99%
- B: 70–79.99%
- C: 60–69.99%
- D: 50–59.99%
- E: below 50% (if all subjects are passed)
- F: fail if any subject mark is below 35

These are example rules for the project and can be changed in `script.js`.

## Files
- `index.html` — page structure
- `style.css` — page design
- `script.js` — calculation and grading logic
